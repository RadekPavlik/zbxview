Přidání serveru QR kódem

V Zabbixu otevřete „Připojení telefonu“ a naskenujte QR kód — server i přihlášení jsou hotové. Spojení platí, dokud nespárujete znovu. Stačí modul ZbxView connect.

🪪

Klientský certifikát (mTLS)

Pro Zabbix za bránou, která vyžaduje certifikát (např. Cloudflare): nahrajte ho u serveru, pošlete přes MDM, nebo ho dostanete rovnou v QR kódu při párování.

🔔

Push notifikace přes váš Firebase

Firma si založí vlastní Firebase projekt, na Zabbix serveru běží malá relay služba a telefony dostávají problémy jako notifikace. Údaje projektu přinese QR kód modulu ZbxView connect nebo MDM. Návod.

🔒

Zámek aplikace

Otisk, obličej nebo PIN při otevření. Přihlašovací údaje zůstávají v úložišti zařízení.

Párování

Telefon připojený k Zabbixu za pár vteřin

Modul ZbxView connect do Zabbixu (6.4–8.0) přidá v Uživatelském nastavení položku „Připojení telefonu“. Nikdo nic nevypisuje ani neopisuje tokeny.

1

Otevřete „Připojení telefonu“

Hned se zobrazí QR kód pro první zařízení. Každý telefon dostane vlastní API token, který nevyprší.

2

Naskenujte v aplikaci

Přidat server → Naskenovat QR kód. Aplikace ukáže, co kód obsahuje, a server přidá i s přihlášením.

3

Víc telefonů? Seznam zařízení

Stránka ukazuje všechna spárovaná zařízení. „Přidat další zařízení“ připojí další telefon nebo tablet, „Nový QR kód“ znovu spáruje jedno zařízení a koš ho odebere — ztracený telefon tak přijde o přístup, ostatní fungují dál.

🪪

Certifikát v QR kódu

Správce může do modulu nahrát společný klientský certifikát (klíč EC). Kód je pak větší, a proto se rozdělí na tři kódy, které se střídají. Aplikace si načte všechny a certifikát uloží sama (od verze 0.49).

⚙️

Nastaví správce jednou

Adresu, na které telefony Zabbix najdou (např. přes Cloudflare), jméno serveru a práci s certifikáty nastaví správce v Administrace → Konfigurace telefonu, kde nahraje i klientský certifikát a modul ho rovnou zkontroluje — uživatel nic nevyplňuje.

🔐

Bezpečně

Kód se zobrazí jen jednou a po 5 minutách nebo tlačítkem „Skrýt hned“ zmizí. Jakmile ho telefon naskenuje, stránka to pozná a kód schová; kód, který nikdo nenaskenoval, se zahodí i s tokenem. Token je běžný API token uživatele s jeho oprávněními, vidíte ho i v API tokenech.

Jak modul nainstalovat (jednou, správce Zabbixu)

  1. Stáhněte modul z GitHubu a nakopírujte ho do adresáře modulů Zabbix frontendu:
cd /usr/share/zabbix/modules
git clone https://github.com/RadekPavlik/Zabbix-UI-Modules-ZbxView-connect.git
  1. V Zabbixu otevřete Administrace → Obecné → Moduly, klikněte na Skenovat adresář a modul ZbxView connect zapněte.
  2. V Administrace → Konfigurace telefonu nastavte adresu, na které telefony Zabbix najdou (např. přes Cloudflare), název serveru a certifikát serveru. Pokud je Zabbix za bránou s mTLS, nahrajte tam i klientský certifikát (klíč EC) — modul ho zkontroluje.
  3. Uživatelé pak otevřou Uživatelské nastavení → Připojení telefonu a v aplikaci zvolí Přidat server → Naskenovat QR kód. Hotovo.
Požadavky: Zabbix 6.4–8.0; role uživatele musí povolovat Správu API tokenů a přístup k API. Certifikát v QR kódu umí aplikace od verze 0.49. Novější verzi modulu stáhnete příkazem git pull v jeho adresáři.

Push notifikace

Problémy jako notifikace — přes váš vlastní Firebase

ZbxView nemá žádný cloud uprostřed. Firma si založí vlastní Firebase projekt, na Zabbix serveru běží malá relay služba a notifikace jdou přímo z vašeho Zabbixu do vašich telefonů. Android, aplikace 0.50 a novější.

🔒

Data zůstávají u vás

Notifikace nese jen název problému, hosta, závažnost a číslo události. Detail si aplikace stáhne sama z vašeho Zabbixu. Relay běží u vás a poslouchá jen na localhostu.

📲

Jedno nastavení, všechny telefony

Správce vloží údaje Firebase projektu do modulu ZbxView connect — QR kód je předá každému telefonu a push se zapne hned po naskenování. Nebo je rozešlete přes MDM (klíče push_*).

🤖

Zatím jen Android

Na iOS doručuje Firebase přes APNs a potřebuje klíč vývojáře aplikace, který nelze sdílet. Jedno zařízení používá jeden Firebase projekt.

Jak to zapnout (jednou, správce Zabbixu)

  1. Firebase projekt. Na console.firebase.google.com založte projekt (plán Spark je zdarma) a přidejte do něj Android aplikaci s názvem balíčku app.zbxview. Stáhněte google-services.json. V Project settings → Service accounts vygenerujte nový privátní klíč a uložte ho jako service-account.json — ten patří jen na server, nikdy do telefonu.
  2. Relay na Zabbix serveru. Malá Python služba, která přijme webhook ze Zabbixu a odešle zprávu do Firebase (FCM HTTP v1 vyžaduje podepsaný OAuth token, což webhook v Zabbixu neumí):
sudo mkdir -p /opt/zbxview-push-relay && cd /opt/zbxview-push-relay
for f in push_relay.py config.ini.example zbxview-push-relay.service; do
  sudo curl -fsSLO https://radekpavlik.github.io/zbxview/tools/push-relay/$f
done
sudo cp config.ini.example config.ini        # shared_secret = openssl rand -hex 24
sudo cp ~/service-account.json .             # z Firebase (krok 1)
sudo python3 -m venv venv && sudo venv/bin/pip install firebase-admin
sudo chown -R zabbix:zabbix . && sudo chmod 600 config.ini service-account.json
sudo cp zbxview-push-relay.service /etc/systemd/system/
sudo systemctl enable --now zbxview-push-relay
  1. Typ média „ZbxView Push“. V Upozorňování → Typy médií → Import naimportujte media_type_zbxview_push.yaml a v parametru Auth nastavte shared secret z config.ini. (Ruční varianta: webhook s parametry RelayURL, Auth, SendTo={ALERT.SENDTO}, Subject, Message, EventId={EVENT.ID}, Host={HOST.NAME}, Severity, Status a tímto skriptem.)
  2. Akce. V Upozorňování → Akce → Akce triggerů přidejte operaci Odeslat zprávu uživatelům nebo skupině přes ZbxView Push (pro problém i obnovení). Token telefonu si aplikace zaregistruje do médií uživatele sama — nikdo nic nevyplňuje a Zabbix pošle jen to, na co má uživatel právo.
  3. Údaje projektu do telefonů. V modulu ZbxView connect otevřete Administrace → Konfigurace telefonu, kartu Push notifikace (Firebase), a klepněte na Načíst google-services.json — čtyři hodnoty se vyplní samy. Každý QR kód je od té chvíle nese a telefon si push zapne hned po naskenování. Bez modulu totéž přes MDM: klíče push_api_key, push_app_id, push_sender_id, push_project_id a push_enabled (tabulka klíčů).
  4. Ověření. V aplikaci je v Nastavení → Push notifikace přepínač zapnutý; vyvolejte testovací problém na hostu, který uživatel vidí — notifikace dorazí a klepnutí otevře problém. Když nic nepřijde: journalctl -u zbxview-push-relay a Reporty → Akce v Zabbixu.
Poznámky: aplikace 0.50+ a modul ZbxView connect 1.6+. Firebase u Android aplikace neověřuje vlastníka balíčku, registrace app.zbxview ve vašem projektu je v pořádku. Zabbix 6.4–8.0; soubor YAML je pro 7.0+, v 6.4 založte typ média ručně podle skriptu. Pokud má telefon aplikaci už spuštěnou s jiným projektem, změna se projeví po restartu aplikace.
